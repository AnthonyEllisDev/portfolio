Procedural generation · WebGL

Procedural Galaxy Generator

Every galaxy, star, planet, faction and mountain range is a pure function of one 48-bit seed. Type 7F8A-2C91-BD44 and you get the identical universe on any machine — so the URL is the save file. Zoom from 250,000 stars in a single draw call down to the terrain of one planet's surface.

Arterial — City Traffic Simulator

Draw roads, zone land, watch a city grow and then jam. Every car uses the Intelligent Driver Model to follow, MOBIL to change lanes, and routes itself with A* over lane space — so congestion is an emergent result, never a fudged number.

  • Canvas 2D
  • IDM + MOBIL
  • A* routing

Flocking · Cellular automata

Aquarium & Cellular Automata Sandbox

Thousands of boids steering around a falling-sand bed you can dig, pile and flatten while they swim. Structure-of-arrays typed buffers and a spatial hash keep the flocking O(n) instead of O(n²) — the live telemetry panel proves it.

About

I'm Anthony Ellis, a software engineer and game developer drawn to problems where the interesting part is the system underneath — pathfinding, procedural generation, physics, and the performance work that keeps all of it at 60 frames per second.

I build without engines on purpose. Writing my own spatial index, my own deterministic RNG and my own render loop means that when something drops to 12 fps or a seed stops reproducing, I know exactly which layer to open. Every project here ships as a single self-contained HTML file with no build step for the viewer.

I'm currently looking for work in simulation, gameplay engineering, graphics or tooling — get in touch.
