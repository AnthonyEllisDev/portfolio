Projects

Procedural Galaxy Generator · three.js, GLSL, Web Workers

anthonyellis.dev/projects/galaxy
  • Renders 250,000 stars in a single draw call at 60 fps — 14 bytes per star, with sub-pixel dimming in a custom shader so distant galaxies attenuate correctly instead of getting brighter.
  • Every galaxy, star, planet and terrain patch is a pure function of one 48-bit seed — the URL is the save file, any bug reproduces exactly, and the LOD cache can evict freely because nothing is ever the only copy.
  • Headless-Chromium suite asserts bit-identical star buffers across runs and reads back the framebuffer per view, so a silently black render fails the build.

Arterial — City Traffic Simulator · Canvas 2D, graph algorithms

anthonyellis.dev/projects/arterial

Aquarium & Cellular Automata Sandbox · Canvas 2D, performance

anthonyellis.dev/projects/aquarium
  • Scales flocking from hundreds to 4,000 agents by replacing O(n²) neighbour search with a spatial hash over structure-of-arrays typed buffers — zero allocation per frame.
  • Agents steer around a falling-sand cellular automaton the user reshapes in real time using three O(1) grid probes each, and the renderer degrades by dropping detail at population thresholds rather than dropping frames.
